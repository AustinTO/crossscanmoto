# Optional AI knowledge references, not default agent startup content

Files copied from the earlier CrossScanMoto Companion V3 research package. These are source-grounded **research/reference inventories**: 68 playbooks, ECU/vehicle records, source registry, diagnostic event contract and capability schema. They are NOT a new claim of support in a specific app revision and their own confidence/provenance limitations must be preserved. In particular, recovered table counts are not validated motorcycle-function counts.

For core transport and reverse-engineering tickets, do not load this folder. Consult it only for AI companion work (P2-01 to P2-05) or a ticket explicitly requiring human-readable diagnostic playbooks. Verify everything against current app repo and original source before changing ECU command behavior.
