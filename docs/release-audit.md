# Release audit — 2026-11-01

Features were preserved while fixing:

- service and actuator links addressed to a previous ECU after a selection change;
- stale UDS configuration following a rejected target change;
- mismatched KWP negative responses causing retries or follow-up probes;
- silent 16-bit mileage overflow;
- hanging transport writes beyond command timeout;
- actuator interleaving, lifecycle cancellation and cancellation/wait races;
- Garage profile clearing/hydration and adapter status;
- incomplete purchase test adapters after authenticated backend changes;
- fallback JWT signing, missing session claims/revocation, unprotected account deletion and canonical-account binding;
- checkout availability while store verification credentials are absent.

The vector motorcycle was replaced by generated product artwork and a matching opaque launcher icon across Android, iOS, macOS, web and Windows. The runtime hero WebP is 186,688 bytes versus its 2,126,153-byte PNG master. Phone and desktop screenshots are generated by the UI tests. Existing controls/navigation and diagnostic operations remain available.

Local verification: full Flutter suite and backend suite run after the final changes; exact run counts and artifact hash are reported with delivery. Static analysis, migration smoke checks, signing shell syntax and workflow YAML were checked. Production health/privacy/terms GETs and unauthenticated entitlement rejection were checked. Production DELETE was intentionally not performed after automatic approval review rejected that probe as potentially destructive; deletion behavior was covered in isolated backend tests.

GitHub's Apple workflow builds simulator and unsigned release artifacts automatically on branch pushes. Signed IPA export and TestFlight upload require the documented variables/secrets and explicit workflow dispatch. Hardware validation and live store sandbox transactions remain release gates.
